# QPS Web Admin

## 项目定位

QPS 管理端是通用框架的后台基座：提供登录、权限、动态菜单以及列表页、详情抽屉等通用能力；`views/crm` 与 `views/mall` 是示例业务模块，新项目可按模块整体替换。

框架整体定位见 [根目录 README](../README.md)，示例业务背景见 [项目背景与业务链路](../docs/product/项目背景与业务链路.md)。

## 技术栈

- Vue 3
- TypeScript
- Vite
- Element Plus
