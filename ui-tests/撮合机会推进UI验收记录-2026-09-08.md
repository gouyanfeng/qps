# 撮合机会推进 UI 验收记录

**验收日期：** 2026-09-08
**验收环境：** Edge，`http://127.0.0.1:5174`，`http://127.0.0.1:5001/api`
**测试数据前缀：** `QPS推进验收_20260908`

## 结果

| 场景 | 结果 | 页面回查 |
| --- | --- | --- |
| 创建机会 | 通过 | 候选筛选页仅提供“匹配核实”适用待办；选择“其他”后显示且要求填写“其他待办说明”。创建后列表显示阶段、当前待办和计划时间。 |
| 列表快捷推进 | 通过 | 列表“推进”打开共享弹窗，阶段仅可在“匹配核实”和“商务沟通”间相邻选择。提交后列表显示“商务沟通 / 沟通价格”。 |
| 详情回查 | 通过 | 详情快照显示阶段、当前待办、计划时间；时间线新增“推进”记录，包含阶段、本次结果、待办和计划时间。 |
| 暂停与恢复 | 通过 | 详情暂停后，列表“推进”弹窗按钮改为“恢复并推进”。提交后状态恢复为“推进中”，并记录恢复推进结果。 |
| 自动化回归 | 通过 | `npx playwright test crm-05-match-opportunity.spec.mjs`：1 passed，43.5 秒。覆盖创建、候选、中选淘汰、两次阶段推进、暂停恢复、意向确认和成功关闭。 |

验收开始时发现 `5001` 仍运行 2026-09-07 的旧调试二进制，导致候选查询返回 404。仅停止并更新隔离端口 `5001`，执行迁移 `20260908030759_AddCrmMatchOpportunityProgress` 后以当前 Release 构建重启；开发环境 `5000/5173` 未改动。
