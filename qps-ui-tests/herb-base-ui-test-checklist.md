# 基地管理 UI 功能测试清单

- 登录与壳：登录页、登录后布局、水印、标签页。
- 页面巡检：所有菜单页面可打开，无白屏、无控制台错误、无 API 4xx/5xx。
- 主体列表：搜索、重置、展开/收起、分页、主体名称列、基地数、品类、地区、状态、跟进人。
- 列表边界：基地主体与基地明细名称不混用；主体名缺失时显示兜底；空字段显示 `-`。
- 详情抽屉：主体标题、摘要卡片、基地明细、联系人、沟通记录、流转记录。
- 详情数据：真实联系人、电话、微信、沟通内容、流转操作人必须可见。
- 空数据：无基地明细、无沟通记录、无流转记录时显示空态且不报错。
- 操作流：新增基地、编辑主体/基地、分配、记录沟通、新增/编辑联系人、设为主联系人、状态变更。
- 表单校验：基地名称必填、主体名称必填、联系人姓名或电话至少一个、沟通结果必选。
- 权限：无分配/新增/编辑/沟通/联系人/状态权限时按钮隐藏；有权限时可操作。
- 真实接口：本地后端关键接口返回成功，前端能打开真实详情并展示真实数据。
