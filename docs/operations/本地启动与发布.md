# 本地启动与发布

本文档是 QPS 当前仓库唯一的运行指引。研发历史计划、根 README 和子项目 README 中不重复维护启动命令；其中的旧路径和命令均以本文为准。

## 目录与端口

- 后端：`web-api/`，调试端口 `5000`。
- 管理端：`admin/`，开发端口 `5173`。
- 移动端：`mobile/`，uni-app 项目，H5 开发端口 `5174`，用于避开管理端的 `5173`。当前页面数据来自 `mobile/src/mock/` 本地模拟数据，尚未接入后端接口。
- 本地 IIS 后端：`20004`，用于 IIS 发布后的接口验证；管理端开发环境的 `.env` 使用 `http://localhost:5000/api`。
- 本地 IIS 管理端：`20005`，物理路径为 `admin/dist/`。
- Playwright UI 测试使用隔离前端 `6174` 和隔离后端 `5001`；测试脚本、截图和报告放在 `ui-tests/`，不提交仓库。

## 开发启动

独立启动后端调试服务：

```powershell
dotnet run --project .\web-api\src\4.QPS.WebAPI\QPS.WebAPI.csproj -- --urls http://localhost:5000
```

启动管理端：

```powershell
Set-Location .\admin
npm run dev
```

本地开发使用前端 `http://127.0.0.1:5173`、后端 `http://localhost:5000/api`。开发前端端口被占用时应释放占用进程后重启，不得自动改用其他端口。

启动移动端（H5）：

```powershell
Set-Location .\mobile
npm run dev:h5 -- --port 5174 --strictPort
```

访问 `http://127.0.0.1:5174`。开发微信小程序等其他端时改用对应脚本，例如 `npm run dev:mp-weixin`。

## Playwright UI 测试

Playwright UI 测试固定使用隔离前端 `http://127.0.0.1:6174` 和隔离后端 `http://127.0.0.1:5001/api`。测试端口被占用时，只释放对应的测试进程；不得停止、复用或占用开发环境的 `5173`、`5174` 与 `5000`，也不使用本地 IIS 的 `20004`。

## 构建验证

```powershell
dotnet restore .\web-api\QPS.sln
dotnet build .\web-api\QPS.sln --no-restore

Set-Location .\admin
npm ci
npm run build
```

前端构建完成后，IIS 的 `CRN_WEB` 站点直接读取 `admin/dist/`。

## 发布到本地 IIS

后端发布目录为 `web-api/src/4.QPS.WebAPI/bin/Release/net8.0/publish/`。发布前先完成构建验证。

```powershell
dotnet publish .\web-api\src\4.QPS.WebAPI\QPS.WebAPI.csproj -c Release
```

若 IIS 锁定 DLL，在发布目录创建 `app_offline.htm`，等待 IIS 卸载应用后再发布；发布完成后删除该文件。最后验证接口：

```powershell
Invoke-WebRequest -Uri "http://localhost:20004/api/admin/crm/herb-bases?page=1&pageSize=1" -UseBasicParsing -TimeoutSec 20
```
