# 本地启动与发布

本文档是 QPS 当前仓库唯一的运行指引。研发历史计划、根 README 和子项目 README 中不重复维护启动命令；其中的旧路径和命令均以本文为准。

## 目录与端口

- 后端：`web-api/`，调试端口 `5000`。
- 管理端：`admin/`，开发端口 `5173`。
- 本地 IIS 后端：`20004`，用于 IIS 发布后的接口验证；管理端开发环境的 `.env` 使用 `http://localhost:5000/api`。
- 本地 IIS 管理端：`20005`，物理路径为 `admin/dist/`。
- Playwright UI 测试、截图和报告：`ui-tests/`，不提交仓库。

## 开发启动

独立启动后端调试服务：

```powershell
dotnet run --project .\web-api\src\4.QPS.WebAPI\QPS.WebAPI.csproj -- --urls http://localhost:5000
```

启动管理端：

```powershell
Set-Location .\admin
npm run dev
```

本地开发和 Playwright UI 测试均使用前端 `http://127.0.0.1:5173`、后端 `http://localhost:5000/api`。前端端口被占用时应释放占用进程后重启，不得自动改用其他端口。

## 构建验证

```powershell
dotnet restore .\web-api\QPS.sln
dotnet build .\web-api\QPS.sln --no-restore

Set-Location .\admin
npm ci
npm run build
```

前端构建完成后，IIS 的 `CRN_WEB` 站点直接读取 `admin/dist/`。

## 发布到本地 IIS

后端发布目录为 `web-api/src/4.QPS.WebAPI/bin/Release/net8.0/publish/`。发布前先完成构建验证。

```powershell
dotnet publish .\web-api\src\4.QPS.WebAPI\QPS.WebAPI.csproj -c Release
```

若 IIS 锁定 DLL，在发布目录创建 `app_offline.htm`，等待 IIS 卸载应用后再发布；发布完成后删除该文件。最后验证接口：

```powershell
Invoke-WebRequest -Uri "http://localhost:20004/api/admin/crm/herb-bases?page=1&pageSize=1" -UseBasicParsing -TimeoutSec 20
```
