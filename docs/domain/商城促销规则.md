# 商城促销规则

> 代码位置：`web-api/src/QPS.Mall/Domain/Services/MallPromotionEngine.cs`（引擎）、`Application/Features/MallOrders/CreateMallOrderCommand.cs`（下单校验）、`admin/src/views/mall/promotion/index.vue`（管理端配置）。

## 1. 统一模型

每条促销由两个固定维度加一个动作构成：

```
促销 = 商品范围（Scope） + 订单门槛（Trigger: FullAmount.minAmount） + 动作（Action）
```

- **商品范围**（`ScopeType`）：`Global` 全场 / `Category` 指定分类 / `Product` 指定商品 / `Sku` 指定规格。
- **订单门槛**（`TriggerType = "FullAmount"`，`triggerConfigJson = { "minAmount": x }`）：**所有促销类型统一使用满额门槛触发**，不再有按件数（BuyProduct）触发的类型。
- **门槛金额的计算口径**：按范围内商品的订单金额累计；范围选 `Global` 时按全订单金额计算。

## 2. 四种促销类型（Action）

| 类型 | actionType | 动作配置 | 规则文本示例 |
|---|---|---|---|
| 满减 | `DiscountAmount` | `{ amount }` 减免金额 | 满 ¥100 减 ¥20 |
| 折扣 | `DiscountRate` | `{ rate }` 折扣比例（0.1~1） | 满 ¥100 打 8.0 折 |
| 买赠 | `Gift` | `{ skuId, quantity }` 赠品规格与数量 | 满 ¥100 赠 1 件赠品 |
| 换购 | `TradeIn` | `{ skuId, quantity, tradeInPrice }` 换购规格、数量、换购价 | 满 ¥100 可加 ¥9.90 换购 1 件 |

管理端不再单独提供「满额换购」类型——换购与满减一样，靠订单门槛触发。

## 3. 生效方式

### 3.1 引擎自动应用（满减 / 折扣 / 买赠）

`MallPromotionEngine` 在计算订单价格时自动匹配并应用：

1. 促销启用、在有效期内、未超出每人/每单使用次数限制；
2. 范围匹配：筛选订单中属于促销范围的订单项；
3. 门槛判断：范围内商品金额合计 ≥ `minAmount`；
4. 满减直接减金额，折扣按比例折算，买赠生成 0 元赠品订单项（带 `IsGift` 标记与促销关联）。

### 3.2 用户选择式（换购）

换购**不**被引擎自动应用（避免 0 元强塞商品），流程为：

1. 移动端结算页调用 `GET /api/mall/promotions/exchange?amount={订单金额}`，后端按当前订单金额返回已达标（订单金额 ≥ 门槛）的换购资格（商品、规格、原价、换购价、限购数）；
2. 用户在结算页「优惠换购」卡片中选择换购品与数量；
3. 提交订单时通过 `exchangeItems` 携带换购项，后端 `CreateMallOrderCommand` 校验：
   - 促销有效且为 `TradeIn` 动作；
   - 订单原价 ≥ 满额门槛（`minAmount`）；
   - 换购规格与配置一致、数量 ≤ 限购（`quantity`）；
   - 库存充足、未超每人限用次数；
4. 校验通过后按**换购价**（非 0 元）生成订单项，记录原价与关联促销，计入订单总额、扣减库存、参与运费计算。

## 4. 通用控制字段

| 字段 | 说明 |
|---|---|
| `Priority` | 优先级，数字越大越先应用 |
| `Combinable` | 是否可与其他促销叠加 |
| `MaxUsagePerUser` | 每人限用次数（0 = 不限） |
| `MaxUsagePerOrder` | 每单限用次数（0 = 不限） |
| `StartDate` / `EndDate` | 有效期（可空 = 长期） |
| `IsActive` | 启用状态 |

## 5. 存量数据兼容

- 历史上存在 `TriggerType = "BuyProduct"`（按件数触发）的买赠/换购促销：展示层兼容读取（列表规则文本按 `minQuantity` 显示「买 N 件…」），仍可正常参与计算；在管理端重新编辑保存后自动统一为 `FullAmount` 结构。
- 门槛 `minAmount` 缺失的存量数据在编辑回显时默认 100。
