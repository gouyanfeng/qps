# 接口契约

本目录存放对外接口边界的事实文档，权威来源始终是 Controller 与 DTO 代码。

## 放什么

- 接口 URL、HTTP 方法、鉴权要求与预置策略。
- 请求与响应字段、类型、必填性、取值枚举。
- 错误码与统一响应格式的实际表现。
- 真实调用示例（经过实测的响应片段）。

## 不放什么

- Handler 内部编排逻辑与实现细节（见 `docs/architecture/`）。
- 数据库表结构与字段含义（见 `docs/domain/`）。
- 页面交互规格（见 `docs/design/`）。

## 命名与维护

- 文件名用 `<module>-<scope>-api.md`，例如 `mall-campaign-api.md`。
- 接口字段变化时同步更新本文档，并刷新元信息块中的「最后核对」日期。
- 与代码不一致时以代码为准，先修文档再提交。
