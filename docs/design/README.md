# 页面设计规格

本目录存放页面形态与交互规格，只描述「长什么样、怎么交互」，不描述后端实现。

## 放什么

- 页面结构与区块划分、交互流程与状态。
- 视觉基准：间距、字号、颜色、组件选型。
- 与设计稿资产的对应关系（以路径链接，不复制资产本身）。

## 不放什么

- 后端接口实现与数据库设计。
- 未经评审的草稿与脑暴。
- 设计稿原始资产（HTML / PNG / JPG），资产留在各端 `design/` 目录。

## 命名与维护

- 文件名用 `<page>-spec.md`，例如 `admin-permissions-spec.md`、`member-health-spec.md`。
- 未落地的设计在元信息块标注 `状态：待实施`，落地后改为 `状态：有效`。
