## 2. 数据来源与结构映射

| 页面概念 | 现有数据 |
| --- | --- |
| 顶部当前角色下拉 | `GET /admin/roles`（`id/name/code`），本环境 2 个角色：普通用户(user)、系统管理员(admin) |
| 角色已授权集合 | `GET /admin/permissions` → `{ [roleCode]: { roleName, permissions: string[] } }` |
| 权限节点 | `GET /admin/permissions/tree`，节点含 `id/code/name/type/children`，`type` 为 `Menu` / `Button` |
| 保存 | `PUT /admin/permissions { role, permissions: code[] }`（保持原样） |

映射规则：

- `ROOT` 为树根，不在矩阵中显示、不可编辑；保存时按该角色原有状态保留（admin 含 ROOT，user 不含），避免改动存量语义。
- `ROOT` 的直接 `Menu` 子节点 = 模块分组（CRM管理 / 商城管理 / 系统设置 / 首页）。
- 分组内的 `Menu` 后代节点 = 矩阵的「页面行」；页面行的 `Button` 子节点 = 「操作按钮授权」单元格。
- 顶层 `Menu` 若没有子菜单（如首页、商城管理），直接作为页面行展示。
- 保存集合 = 勾选的页面 Menu + 勾选的 Button + 自动补齐的祖先 Menu + 保留的 ROOT。勾选任一按钮会自动带上其页面与模块，保证菜单路由可见。

## 3. 两栏职责与联动路径

1. **矩阵区**：顶部模块筛选 chips + 行搜索 + 「全部展开 / 全部收起」+「全选访问」；主体为矩阵表格：
   - 分组行：模块名 + code，右侧三态全选框（全选/半选/未选，作用于该组所有页面行的访问开关）。
   - 页面行：页面名 + code（mono 小字），「页面访问权限」列是开关，右侧为该页面的按钮 chips。
2. **右栏｜修改记录**：相对已保存集合的实时 diff，卡片标注「新增授权 / 取消授权」+ 路径 + code；顶部显示待保存数量与「撤销所有」；保存后清空。

联动路径：

- 角色切换入口只保留顶部角色下拉（不设左栏角色列表，也无下拉与列表的双向同步）→ 选择后载入该角色勾选态到矩阵与右栏 diff 基准。
- 切换角色：载入新角色权限，未保存变更直接丢弃（与现有行为一致）。
- 勾选页面开关 → 关闭时自动取消并锁定该页按钮（按钮 chips 进入只读态），同时刷新右栏 diff；打开时不自动勾选按钮。
- 勾选按钮 → 自动同时勾选其页面与祖先模块（只影响展示与保存集合，不产生额外 diff 卡片以外的节点）。
- 模块 chip / 搜索 → 只过滤当前展示的行，不影响已勾选集合与 diff 计算。
- 重置 / 撤销所有 → 恢复到该角色已保存集合；保存 → PUT 成功后以当前集合为新基准。

## 4. 矩阵控件形态

- **全选（分组行）**：`el-checkbox` 三态。组内页面全选 = 选中；部分 = indeterminate 半选；点击半选/未选 = 全选该组页面的「页面访问」；点击已选 = 全部取消（并联动清空按钮）。
- **页面访问开关**：`el-switch`，开=「允许访问」（主色 #009688），关=「已禁用」（灰色）；页面关闭时整行按钮区降透明度并锁定。
- **按钮单元格**：`el-checkbox` 内联流式排列，文案使用权限名称；`code` 以 tooltip 展示。删除类（code 结尾 `_DELETE`）加「高危」红色小标签，但仍可授权（现有系统没有后端锁定策略，不做假只读）。
- **只读态**：仅两种：`ROOT` 不可见/不可编辑；页面关闭后其按钮 chips 与组内联动处于 disabled。不引入角色级只读。
- **空态**：过滤后无命中显示「没有匹配的权限」；角色无权限时矩阵照常可操作。

## 5. 与现有权限页的差异

| 现状 | 新稿 |
| --- | --- |
| 左栏角色、中栏 `el-tree` 全展开树、右栏修改记录 | 两栏：矩阵表格（分组行 + 页面行 + 按钮 chips）+ 右栏 diff 卡片；角色切换收在顶部下拉 |
| 每个节点一个 checkbox，菜单/按钮混排 | 菜单=行 + 开关，按钮=单元格 chips；树层级用分组行 + 缩进表达 |
| 顶部无角色栏；保存/重置在右栏 | 顶部角色栏含当前角色、授权数量徽标、重置、保存权限；右栏保留「撤销所有」 |
| 无过滤/搜索/全选 | 模块 chips、行搜索、全部展开/收起、全选访问 |
| 菜单/按钮标签（本次改造） | 保留语义：矩阵中「菜单」= 页面行，`Button` = 按钮 chips；不再逐节点渲染类型标签，改由控件形态区分 |

## 6. 视觉参数（落地取值）

- 主色 `#009688`：顶部主按钮、开关选中态、chip 选中态、勾选框、徽标文字、选中模块 chip；不新增大面积主色块。
- 页面底色 `#f5f7fa`；卡片白底 `#fff`；边框 `--el-border-color-lighter`；卡片阴影 `0 1px 3px rgba(15,23,42,.06)`。
- 圆角：卡片 8px；输入框/按钮/chip 4px；状态徽标 999px。
- 间距：页面 16px；卡片内 12–16px；表格单元格 10px 12px；chips 间距 8px。
- 字号：页面标题/角色名 14px 600；正文 13px；辅助/说明 12px；code 等宽 11px。
- 行高：分组行 40px，页面行 ≥ 44px。
- 布局：顶部角色栏 56px；两栏右侧固定 `320px`、矩阵区 `flex: 1; min-width: 0` 占满剩余宽度，两栏内部各自滚动，页面整体不出现横向滚动（≤1360px 纵向堆叠）。

## 7. 后端接口结论

无需新增接口，也无需改接口：

- 树接口已有 `type` 参数，本次页面拉取完整树（不传 type），`type` 字段用于区分行与单元格。
- 保存沿用 `PUT /admin/permissions`，提交 code 数组；自动补齐祖先不影响接口兼容。
- 设计稿里的「已生效 (34人)」与「历史日志 / 最近审计归档」在现有接口中没有数据来源，**不造假**：徽标改为「已授权 N 项」，右栏只保留「本次变更」，不实现无数据的历史日志页签。

## 8. 验收点

1. 5173 打开 `/#/system/permission`，默认载入第一个角色，矩阵按模块分组展示，页面行与按钮 chips 可区分。
2. 菜单/按钮类型改造不回退：`Button` 节点只出现在按钮单元格，`Menu` 节点只作为页面行/分组。
3. 关闭某页面开关后，该页按钮变灰不可点；再次打开恢复可点。
4. 分组三态框全选/半选/取消与组内页面一致；「全选访问」只作用于当前过滤后可见页面。
5. 勾选若干项后右栏出现对应 diff 卡片与数量；「撤销所有」恢复；保存成功后刷新仍保持。
6. 1600×1000 截图覆盖：默认态、按钮授权态、过滤态、菜单/按钮形态对照。
