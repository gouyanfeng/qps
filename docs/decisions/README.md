# 架构决策记录（ADR）

本目录存放已确认的架构与业务取舍，回答「为什么这样选」，不承担操作步骤与实现全集。

## 编号规则

- 文件名用 `adr-0001-<slug>.md`，编号 4 位、只增不减。
- 删除或废弃的 ADR 保留编号，在状态中标注「已取代」或「废弃」，并写明取代者。
- 新增 ADR 使用当前最大编号加一，不复用空号。

## 状态取值

只有四种：`提议`、`已接受`、`已取代`、`废弃`。被取代的必须写「取代者：ADR-XXXX」。

## 正文结构

每条 ADR 只回答一个问题，正文固定四段：

1. 背景：当时面对什么约束或问题。
2. 决策：最终选择了什么。
3. 被放弃的方案：还考虑过什么，为什么放弃。
4. 影响：这条决策带来的后果与后续约束。
