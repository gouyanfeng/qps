# CRM厂商与通用联系人改造实施计划

> **给执行代理的要求：** 实施本计划时必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。任务步骤使用复选框（`- [ ]`）跟踪进度。

**目标：** 新增 CRM 厂商模型，承接中药材天地网药企求购线索；将 `CrmContacts` 从“客户联系人表”改造成“通用业务实体联系人表”；厂商品类写入现有 `CrmBusinessEntityAttributes`。

**架构：** `CrmContacts` 直接改为 `EntityType + EntityId`，不保留 `CustomerId` 兼容字段。新增 `CrmVendors` 作为厂商主表，一家药企一行；新增 `CrmVendorPurchasePlans` 作为采购计划子表，一次采购计划一行。品类不放进厂商主表，而是写入 `CrmBusinessEntityAttributes`，`EntityType='CRM_VENDOR'`。

**技术栈：** SQL Server、EF Core、MediatR、xUnit、.NET 8；一次性本地数据库迁移和导入脚本放在 `C:\Users\Dust\AppData\Local\Temp\QPS`。

## 全局约束

- 所有沟通和交付说明使用中文。
- 本计划文档经用户明确允许，放在仓库 `docs/superpowers/plans`。
- 临时 SQL、验证脚本、导入脚本统一放在 `C:\Users\Dust\AppData\Local\Temp\QPS`。
- OCR 原文、图片地址、HTML、RawHtml 不进入新 CRM 厂商表。
- `PendingReview` 和 `Invalid` 数据不进入新表。
- `CrmContacts` 不做兼容保留：删除 `CustomerId` 语义，改为 `EntityType + EntityId`。
