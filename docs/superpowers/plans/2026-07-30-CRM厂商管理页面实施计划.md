# CRM厂商管理页面 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 新增只读的 CRM 厂商管理页面，展示厂商、联系人、采购品类和采购计划。

**架构：** 后端新增 `CrmVendors` 查询 DTO、列表查询、详情查询和控制器；前端新增 `crmVendor` API 模块、`/crm/vendor` 页面和菜单入口。第一版只读，不修改清洗导入数据。

**技术栈：** .NET 8、EF Core、MediatR、SQL Server、Vue 3、Element Plus、QueryPage。

## 全局约束

- 所有沟通和交付说明使用中文。
- 页面只读，不新增、编辑、删除厂商数据。
- 业务数据来自 `CrmVendors`、`CrmVendorPurchasePlans`、`CrmContacts`、`CrmBusinessEntityAttributes`。
- 厂商联系人固定 `EntityType='CRM_VENDOR'`。
- 厂商品类固定 `AttributeCode='PURCHASE_PRODUCT'`。
- 前端和后端测试产物放到 `C:\Users\Dust\AppData\Local\Temp\QPS`。
