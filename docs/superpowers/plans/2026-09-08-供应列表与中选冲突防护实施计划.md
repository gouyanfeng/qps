# 供应列表与中选冲突防护实施计划

> **供智能代理执行：** 必须使用 `superpowers:subagent-driven-development` 或 `superpowers:executing-plans` 逐项执行；步骤使用复选框跟踪。

**目标：** 提供全局供应列表，并防止一条供应在多个未关闭撮合机会中重复中选。

**架构：** Application 层新增供应分页 Query，聚合供应、基地和撮合候选关系并输出占用摘要。撮合命令在中选与撮合成功关闭时调用同一校验器。Vue 页面调用新接口，以筛选表格展示供应和占用情况。

**技术栈：** .NET 8、EF Core 8、MediatR、Vue 3、TypeScript、Element Plus。

**设计：** `docs/superpowers/specs/2026-09-08-供应列表与中选冲突防护设计.md`

## 全局约束

- 自动化测试文件放在 `E:\Code\QPS\codex-temp`。
- 仅修改完成供应查询、候选占用校验和供应列表所需的源码与菜单配置。

```csharp
public static async Task EnsureSupplyNotSelectedElsewhereAsync(
    IDbContext dbContext, Guid supplyId, Guid opportunityId, CancellationToken cancellationToken)
{
    var occupied = await dbContext.CrmMatchCandidates.AnyAsync(candidate =>
        candidate.HerbBaseSupplyId == supplyId &&
        candidate.MatchOpportunityId != opportunityId &&
        candidate.Status == CrmMatchCandidate.Selected &&
        dbContext.CrmMatchOpportunities.Any(opportunity =>
            opportunity.Id == candidate.MatchOpportunityId &&
            opportunity.Status != CrmMatchOpportunity.Closed), cancellationToken);
    if (occupied) throw new BusinessException(400, "供应信息已在其他撮合机会中中选");
}
```

在 `candidate.Select()` 前调用该方法；撮合成功关闭时遍历本机会中选供应再次调用。实现供应列表 Query，投影候选次数、中选次数和需求摘要。
