# 研发文档

本目录保存研发设计、实施计划和可复用验收清单。

```text
superpowers/
  specs/    已确认的设计方案
  plans/    按设计方案编写的实施计划
  testing/  可复用的业务验收清单
```

## 使用规则

- `specs/` 与 `plans/` 使用 `YYYY-MM-DD-中文主题.md` 命名；新文档名称使用中文。
- 设计方案确认后再编写实施计划，计划必须链接对应设计方案。
- 历史文件用于追溯当时的决策；其中的旧路径、命令和环境说明不作为当前执行指引。
- 当前可执行的启动、构建和发布步骤见 [本地启动与发布](../operations/本地启动与发布.md)。
- 临时脚本、截图、构建输出和调试产物存放在 `C:\Users\Dust\AppData\Local\Temp\QPS`，不进入本目录。
