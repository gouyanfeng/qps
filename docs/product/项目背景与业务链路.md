# 项目背景与业务链路

## 项目定位

本项目是面向中药材供应链的供需撮合与客户关系管理平台。

平台服务两类业务主体：

- 药材基地、合作社及供应商：中药材供给方。
- 药厂及相关采购企业：中药材需求方。

平台的目标是统一管理双方档案、供给信息、采购需求和沟通过程，协助业务人员发现供需匹配机会、推进交易并沉淀合作数据。

## 当前交付阶段

当前系统处于“双方 CRM 与采购线索管理”阶段，已交付药材基地主体和基地、药企厂商、联系人、双方跟进记录、厂商采购计划、负责人分配和基础权限管理。

其中，基地记录种植规模、地区、来源和主营品类等基础信息；厂商采购计划保存来源页面中的采购品类和数量摘要。系统尚未提供标准化供给信息、标准化采购需求、候选匹配、撮合机会、报价样品、成交归因和复购管理。

## 业务角色

| 角色 | 业务目标 | 核心信息 |
| --- | --- | --- |
| 供给方基地 | 提供符合采购要求的中药材供给 | 品种、产地、可供量、产新期、规格等级、质量认证、价格预期、物流能力 |
| 需求方药厂 | 获取满足生产计划的中药材原料 | 采购品类、规格等级、需求量、目标价格、交期、质量要求、收货地 |
| 平台业务人员 | 识别匹配机会并促成双方合作 | 联系人、沟通记录、需求状态、撮合进度、成交结果 |

## 目标业务链路

```text
供给方建档 -> 供给信息维护
                         -> 供需匹配 -> 撮合推进 -> 成交与复购
需求方建档 -> 采购需求维护
```

以下是平台的目标业务链路，不代表所有步骤已经实现：

1. 建立药材基地与药厂档案，维护主体、联系人、区域、主营或采购品类等基础信息。
2. 供给方登记可供应的中药材信息，包括品种、产地、数量、规格、质量条件和供货周期。
3. 需求方登记采购需求，包括采购品类、规格、数量、交期、质量标准和目标价格。
4. 业务人员依据品类、规格、产地、数量、交期和质量条件筛选候选供给方，建立撮合机会。
5. 记录双方沟通、报价、样品、验收、谈判和下一步跟进事项，持续推进撮合。
6. 对成交或未成交结果进行归档，沉淀成交品类、合作规模、失败原因和后续复购机会。

## 目标业务对象

- 药材基地：供给方业务档案及其种植、供应能力。
- 药企厂商：需求方业务档案及其采购需求。
- 联系人：与基地或厂商关联的业务联系人及主联系人。
- 跟进记录：电话、拜访、会议等沟通历史，以及下一步计划。
- 采购计划：当前为药厂采购线索的来源记录；后续演进为具有规格、数量、交期、质量和价格条件的标准化采购需求。
- 撮合机会：后续建设，用于承接一个采购需求与一个或多个候选基地之间的业务推进过程。

## 当前系统范围

当前系统已提供工作台、药材基地、药企厂商、联系人、跟进记录、采购计划、用户角色权限、区域字典和日志管理等能力。它可以用于收集和跟进两侧线索，但不能替代撮合台账或交易管理。

后续演进应先完成供给标准化和需求标准化，再建设候选匹配、撮合阶段、报价样品、成交归因和复购管理，形成完整闭环。
