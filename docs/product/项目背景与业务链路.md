# 项目背景与业务链路

## 项目定位

本项目是面向中药材供应链的供需撮合与客户关系管理平台。

平台服务两类业务主体：

- 药材基地、合作社及供应商：中药材供给方。
- 药厂及相关采购企业：中药材需求方。

平台的目标是统一管理双方档案、供给信息、采购需求和沟通过程，协助业务人员发现供需匹配机会、推进交易并沉淀合作数据。

## 当前交付阶段

当前系统处于“双方 CRM 与供需信息标准化”阶段，已交付药材基地主体和基地、药企厂商、联系人、双方跟进记录、跟进任务、负责人流转、基地供应信息、厂商采购需求和基础权限管理。

其中，基地记录种植规模、地区、来源和主营品类等基础信息，供应信息记录具体基地的可供量、规格、质量条件、供货周期、价格预期和有效期；厂商采购需求以逐品类明细维护数量、规格、质量要求、价格和交期。系统尚未提供候选匹配、撮合机会、报价样品、成交归因和复购管理。

## 业务角色

| 角色 | 业务目标 | 核心信息 |
| --- | --- | --- |
| 供给方基地 | 提供符合采购要求的中药材供给 | 品种、产地、可供量、产新期、规格等级、质量认证、价格预期、物流能力 |
| 需求方药厂 | 获取满足生产计划的中药材原料 | 采购品类、规格等级、需求量、目标价格、交期、质量要求、收货地 |
| 平台业务人员 | 识别匹配机会并促成双方合作 | 联系人、沟通记录、需求状态、撮合进度、成交结果 |

## 目标业务链路

```text
供给方建档 -> 供给信息维护
                         -> 供需匹配 -> 撮合推进 -> 成交与复购
需求方建档 -> 采购需求维护
```

以下是平台的目标业务链路，不代表所有步骤已经实现：

1. 建立药材基地与药厂档案，维护主体、联系人、区域、主营或采购品类等基础信息。
2. 供给方登记可供应的中药材信息，包括品种、产地、数量、规格、质量条件和供货周期。
3. 需求方登记采购需求，包括采购品类、规格、数量、交期、质量标准和目标价格。
4. 业务人员依据品类、规格、产地、数量、交期和质量条件筛选候选供给方，建立撮合机会。
5. 记录双方沟通、报价、样品、验收、谈判和下一步跟进事项，持续推进撮合。
6. 对成交或未成交结果进行归档，沉淀成交品类、合作规模、失败原因和后续复购机会。

## 目标业务对象

- 药材基地：供给方业务档案及其种植、供应能力。
- 药企厂商：需求方业务档案及其采购需求。
- 联系人：与基地或厂商关联的业务联系人及主联系人。
- 跟进记录：电话、拜访、会议等沟通历史，以及下一步计划。
- 采购需求：药厂的结构化需求单，包含来源、联系人、状态、交期、收货地及逐品类明细。
- 撮合机会：后续建设，用于承接一个采购需求与一个或多个候选基地之间的业务推进过程。

## 当前系统范围

当前系统已提供工作台、药材基地、供应信息、药企厂商、采购需求、联系人、跟进记录、用户角色权限、区域字典和日志管理等能力。它可用于结构化维护和跟进两侧供需线索，但不能替代撮合台账或交易管理。

后续演进应先完成供给标准化和需求标准化，再建设候选匹配、撮合阶段、报价样品、成交归因和复购管理，形成完整闭环。

## CRM 业务闭环路线图

**更新时间：** 2026-09-03

**当前优先级：** 供需匹配与撮合

### 已完成里程碑

- 基地主体、基地明细、厂商档案，以及联系人、主联系人和沟通记录。
- 负责人流转、流转记录和跟进任务工作台。
- 厂商采购需求标准化、状态流转、厂商详情维护和统一品类字典。
- 基地历史组合、模糊和规格品类清洗。
- 基地供应信息、有效期和状态管理。

采购需求和供应信息已实现结构化维护：采购需求可明确记录需求方、品类、数量、规格、质量要求、价格、交期和收货地；供应信息可记录品类、可供量、规格、质量条件、产新期、价格预期和供货周期。

### 持续治理

- 泛化品类“中药材、其他中药材”等原始来源回查与补全。

该事项不阻塞核心业务功能建设；无法从原始来源确认的记录保留泛化品类，不作猜测性覆盖。

### 下一阶段：供需匹配与撮合

1. 按品类、地区、数量、交期和质量条件筛选候选基地。
2. 建立撮合机会，关联一条采购需求与多个供应候选。
3. 记录报价、样品、验收、谈判和下一步动作。
4. 记录成交、流失、失败原因和复购机会。
5. 建设匹配漏斗、转化率和品类供需看板。

在匹配口径和撮合机会模型完成前，不建设自动推荐、报价样品或成交管理功能。该阶段完成后，平台可从采购需求出发完成候选供给方筛选、撮合推进和结果复盘。
