# CRM 通用记录组件与接口实施计划

> **执行说明：** 按任务逐项实施并验证；运行时代码不保留旧联系人、沟通记录或流转入口。

## 语义重命名影响清单

本次不重命名实体、数据表、实体编码、属性编码、权限码或字典值。`CrmContact`、`CrmFollowRecord`、`CrmTransferRecord` 仍分别保留；仅统一应用层对象范围及 Web API 路由，因此不需要数据库迁移或历史数据对账。

## 任务 1：统一联系人应用层

**文件：**
- 修改：`qps-ht/src/2.QPS.Application/Features/Crm/CrmContacts/*.cs`
- 删除：`qps-ht/src/2.QPS.Application/Features/Crm/CrmVendors/CreateCrmVendorContactCommand.cs`
- 修改：`qps-ht/tests/QPS.UnitTests/Features/Crm/CrmContacts/CrmContactCommandTests.cs`

1. 先增加失败测试，覆盖厂商联系人创建、更新、设主、启停及越界对象拒绝。
2. 为四类联系人命令引入内部对象范围（基地主体或厂商），统一校验对象和联系人归属。
3. 以小范围 `switch` 同步基地主体或厂商的联系人摘要。
4. 删除厂商专用创建命令，运行联系人单元测试。
