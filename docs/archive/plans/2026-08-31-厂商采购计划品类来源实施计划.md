# 厂商采购计划品类来源实施计划

> **已废弃：** 本计划已由 [采购需求实施计划](2026-09-01-采购需求实施计划.md) 替代。采购计划已迁移为采购需求，后续实现不得执行本文任务。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 将厂商采购品类收敛为采购计划的子属性，并让厂商聚合查询只使用采购计划品类。

**架构：** `CrmBusinessEntityAttributes` 保存采购计划的多选品类，`EntityType` 为 `CRM_VENDOR_PURCHASE_PLAN`，`EntityId` 为采购计划 ID。采购计划命令整体替换本计划的品类属性；厂商详情、列表、筛选和首页按有效计划品类去重聚合。

**技术栈：** .NET 8、EF Core、MediatR、SQL Server、Vue 3、TypeScript、Element Plus。

**设计：** `docs/superpowers/specs/2026-08-31-厂商采购计划品类来源设计.md`

## 全局约束

- 使用 `CrmBusinessEntityAttributes`，不新增采购品类独立表。
- 旧 `Products` 文本仅保留历史回查，不再作为输入或查询来源。
- 临时测试、脚本和截图放在 `C:\Users\Dust\AppData\Local\Temp\QPS`。
- 所有页面文案使用中文。
