# 归档目录

本目录只读存放已完成或已失效的过程产物，不参与开发、不进阅读器、不在根 `AGENTS.md` 索引中逐条列出。

## 子目录

| 目录 | 内容 |
|---|---|
| `plans/` | 已完成的实施计划，保留 `YYYY-MM-DD-` 前缀 |
| `specs/` | 历史需求规格与设计快照 |
| `testing/` | 验收记录、测试清单 |
| `audits/` | 一次性审计报告与数据快照 |
| `changelogs/` | 已完成功能的落地记录 |

## 归档规则

- 内容失效时移动到对应子目录，不删除，保证历史决策可追溯。
- 文件名转英文 slug，保留原日期前缀；无日期时按首次提交月份补 `YYYY-MM-DD-`。
- 正文内容不修改，只在文件顶部补一行状态说明：`> 已归档 | 归档日期：YYYY-MM-DD | 替代文档：...`。
- 被取代的文档在归档说明中写清取代者；与另一份重复的文档合并到权威文件后再归档。
- 归档内容不进入 `docs/docs-viewer.html`，也不在根 `AGENTS.md` 索引中逐条出现。
